After you configure a block in Optimalify, you place it on your pages using Shopify's
**customer account editor**. This is the same editor you use to style your account and
Order status pages.

## Open the editor

Two ways:

- **From Optimalify:** open any block (e.g. Banner) and click **"Open the customer account
  editor →"** under the preview. This opens the editor in a new tab.
- **From Shopify admin:** go to **Settings → Customer accounts**, then open the
  customer-account **Editor** (also reachable from **Online Store → Themes** for stores using
  the accounts editor). You'll see the account pages on the left: **Orders**, **Order
  status**, **Profile**.

## Add a block

1. In the editor, pick the page where you want the block (for example **Order status**).
2. Click **Add block** (or **Add app block**) in the section where it should appear.
3. Choose the Optimalify block from the list:
   - **Optimalify Banner**
   - **Optimalify Support**
   - **Optimalify Badges** (trust badges)
   - **Optimalify Payment Icons**
   - **Optimalify Profile**
   - **Optimalify Social Links**
   - **Optimalify FAQ**
   - **Optimalify Store policies**
   - **Optimalify Rich Content**
4. Drag it to the position you want.
5. Click **Save** in the editor.

Where each block can go:

| Block | Available pages |
|---|---|
| Banner | Orders, Order status |
| Support | Footer (all account pages) |
| Trust badges | Order status (after fulfillment details) |
| Payment icons | Order status, Orders, Profile, footer |
| Profile capture | Profile, Orders, Order status |
| Social links | Order status, Orders, Profile, footer |
| FAQ | Order status, Orders, Profile |
| Store policies | Order status, Orders, Profile |
| Rich content | Order status, Orders, Profile, footer |

## Choose which entry a block shows — the "Entry handle"

Banner, Support, Trust badges, and Payment icons let you create **more than one entry** in
Optimalify (for example, two different banners). When you place a block in the editor, it has
one setting:

- **Entry handle** — type the handle of the entry you want this placement to show.
- **Leave it blank** to show your shop **default** (the first active entry).

This means you can place the *same* block on two pages and show a *different* entry on each —
e.g. a "Holiday sale" banner on Orders and a "Delivery delays" banner on Order status. You'll
find each entry's handle in Optimalify on the block's list page.

## Turn it on

A block only appears when **both** are true:

1. The entry is **Active** in Optimalify (not Draft), **and**
2. The block is **added and saved** in the customer account editor.

Only logged-in customers see customer account pages, so preview while signed in.
