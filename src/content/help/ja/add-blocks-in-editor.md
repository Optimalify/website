Optimalifyでブロックを設定したら、Shopifyの**チェックアウトと顧客アカウントのエディター**を使ってページに配置します。アカウントページや注文状況ページのスタイルを調整するときに使うエディターと同じものです。

## エディターを開く

2つの方法があります。

- **Optimalifyから：** 任意のブロック（例：バナー）を開き、プレビューの下にある**「顧客アカウントのエディターを開く →（Open the customer account editor →）」**をクリックします。エディターが新しいタブで開きます。
- **Shopify管理画面から：** **設定 → 顧客アカウント（Settings → Customer accounts）**に進み、顧客アカウントの**エディター（Editor）**を開きます（アカウントエディターを使っているストアでは、**オンラインストア → テーマ（Online Store → Themes）**からも開けます）。左側にアカウントのページが表示されます：**注文履歴（Orders）**、**注文状況（Order status）**、**プロフィール（Profile）**。

## ブロックを追加する

1. エディターで、ブロックを配置したいページ（例：**注文状況**）を選びます。
2. ブロックを表示したいセクションで、**ブロックを追加（Add block）**（または**アプリブロックを追加（Add app block）**）をクリックします。
3. 一覧からOptimalifyのブロックを選びます。
   - **Optimalify Banner**（バナー）
   - **Optimalify Support**（サポート）
   - **Optimalify Badges**（トラストバッジ）
   - **Optimalify Payment Icons**（お支払いアイコン）
   - **Optimalify Profile**（プロフィール）
   - **Optimalify Social Links**（ソーシャルリンク）
   - **Optimalify FAQ**（よくある質問）
   - **Optimalify Store policies**（ストアポリシー）
   - **Optimalify Rich Content**（リッチコンテンツ）
4. ドラッグして、希望の位置に移動します。
5. エディターで**保存**をクリックします。

各ブロックを配置できる場所は次のとおりです。

| ブロック | 配置できるページ |
|---|---|
| バナー | 注文履歴、注文状況 |
| サポート | フッター（すべてのアカウントページ） |
| トラストバッジ | 注文状況（配送情報の後） |
| お支払いアイコン | 注文状況、注文履歴、プロフィール、フッター |
| プロフィール取得 | プロフィール、注文履歴、注文状況 |
| ソーシャルリンク | 注文状況、注文履歴、プロフィール、フッター |
| よくある質問(FAQ) | 注文状況、注文履歴、プロフィール |
| ストアポリシー | 注文状況、注文履歴、プロフィール |
| リッチコンテンツ | 注文状況、注文履歴、プロフィール、フッター |

## ブロックに表示するエントリーを選ぶ — 「エントリーハンドル」

バナー、サポート、トラストバッジ、お支払いアイコンでは、Optimalify内で**複数のエントリー**を作成できます（例：2種類のバナー）。エディターでブロックを配置すると、設定項目が1つ表示されます。

- **エントリーハンドル（Entry handle）** — この配置箇所に表示したいエントリーのハンドルを入力します。
- **空欄のまま**にすると、ストアの**デフォルト**（最初の有効なエントリー）が表示されます。

これにより、*同じ*ブロックを2つのページに配置し、ページごとに*異なる*エントリーを表示できます。たとえば、注文履歴ページには「ホリデーセール」のバナー、注文状況ページには「配送遅延のお知らせ」のバナーを表示する、といった使い方です。各エントリーのハンドルは、Optimalifyのブロックの一覧ページで確認できます。

## 表示をオンにする

ブロックが表示されるのは、次の**両方**を満たしている場合のみです。

1. エントリーがOptimalifyで**有効（Active）**（下書きではない状態）であること、**かつ**
2. ブロックが顧客アカウントのエディターで**追加され、保存されている**こと。

顧客アカウントのページはログイン中のお客様にしか表示されないため、ログインした状態でプレビューしてください。

うまくいかない場合は、**[よくある質問とトラブルシューティング](faq-troubleshooting.md)**をご覧ください。
