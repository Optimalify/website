Optimalifyでブロックを設定したら、Shopifyの**チェックアウトと顧客アカウントのエディター**を使ってページに配置します。アカウントページや注文状況ページのスタイルを調整するときに使うエディターと同じものです。

## エディターを開く

2つの方法があります。

- **Optimalifyから：** 任意のブロック（例：お知らせバナー）を開き、プレビューの下にある**「顧客アカウントのエディターを開く →（Open the customer account editor →）」**をクリックします。エディターが新しいタブで開きます。
- **Shopify管理画面から：** **設定 → 顧客アカウント（Settings → Customer accounts）**に進み、顧客アカウントの**エディター（Editor）**を開きます（アカウントエディターを使っているストアでは、**オンラインストア → テーマ（Online Store → Themes）**からも開けます）。左側にアカウントのページが表示されます：**注文履歴（Orders）**、**注文状況（Order status）**、**プロフィール（Profile）**。

## ブロックを追加する

1. エディターで、ブロックを配置したいページ（例：**注文状況**）を選びます。
2. ブロックを表示したいセクションで、**ブロックを追加（Add block）**（または**アプリブロックを追加（Add app block）**）をクリックします。
3. 一覧からOptimalifyのブロックを選びます。
   - **Optimalify Announcement banner**（お知らせバナー）
   - **Optimalify Support contact**（お問い合わせ先）
   - **Optimalify Trust badges**（信頼バッジ）
   - **Optimalify Payment icons**（決済アイコン）
   - **Optimalify Profile fields**（プロフィール項目）
   - **Optimalify Social links**（SNSリンク）
   - **Optimalify FAQ**（よくある質問）
   - **Optimalify Store policies**（ストアポリシー）
   - **Optimalify Content section**（コンテンツセクション）
   - **Optimalify Buy again**（もう一度購入）
   - **Optimalify Member wallet**（会員ウォレット）
4. ドラッグして、希望の位置に移動します。
5. エディターで**保存**をクリックします。

各ブロックを配置できる場所は次のとおりです。

| ブロック | 配置できるページ |
|---|---|
| お知らせバナー | 注文履歴、注文状況 |
| お問い合わせ先 | フッター（すべてのアカウントページ） |
| 信頼バッジ | 注文状況（配送情報の後） |
| 決済アイコン | 注文状況、注文履歴、プロフィール、フッター |
| プロフィール項目 | プロフィール、注文履歴、注文状況 |
| SNSリンク | 注文状況、注文履歴、プロフィール、フッター |
| よくある質問 | 注文状況、注文履歴、プロフィール |
| ストアポリシー | 注文状況、注文履歴、プロフィール |
| コンテンツセクション | 注文状況、注文履歴、プロフィール、フッター |
| もう一度購入 | 注文履歴（各商品のボタンは注文状況に表示） |
| 会員ウォレット | プロフィール、注文履歴 |

## ブロックに表示するエントリーを選ぶ — 「エントリーハンドル」

Optimalify内で**複数のエントリー**を作成できるのは、**お知らせバナー**（および独立したページである**カスタムページ**）だけです（例：2種類のバナー）。お問い合わせ先、信頼バッジ、決済アイコン、SNSリンク、FAQ、ストアポリシー、コンテンツセクションは、それぞれ1つのエントリーを編集します。

バナー、お問い合わせ先、信頼バッジ、決済アイコン、SNSリンク、FAQ、ストアポリシー、コンテンツセクションには、エディターで設定項目が1つあります。

- **エントリーハンドル（Entry handle）** — この配置箇所に表示したいエントリーのハンドルです。
- **空欄のまま**にすると、ストアの**デフォルト**（最初の有効なエントリー）が表示されます。

Optimalifyのアプリ内にはエントリーのハンドルが表示されないため、通常はこの項目を使う必要はありません。ページごとに別のバナーを表示したい場合は、ハンドルを空欄のままにして、各バナーの**表示場所（Where to show）**で配置を選んでください。詳しくは[バナーの配置とターゲティング](banner-targeting.md)をご覧ください。

## 表示をオンにする

ブロックが表示されるのは、次の**両方**を満たしている場合のみです。

1. エントリーがOptimalifyで**有効（Active）**（下書きではない状態）であること、**かつ**
2. ブロックが顧客アカウントのエディターで**追加され、保存されている**こと。

顧客アカウントのページはログイン中のお客様にしか表示されないため、ログインした状態でプレビューしてください。

うまくいかない場合は、**[よくある質問とトラブルシューティング](faq-troubleshooting.md)**をご覧ください。
