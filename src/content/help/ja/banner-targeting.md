各バナーを**どこに**表示し、**誰に**見せるかを選べます。バナーは、全員に表示する（デフォルト）か、特定のお客様（タグ、国、言語、B2Bステータス、保存されたプロフィール情報、誕生月、スケジュールなど）に絞って表示できます。

## 表示する場所（配置）

各バナーの配置は、**アプリ → Optimalify → ブロック → バナー → （編集）→ 表示する場所（Apps → Optimalify → Blocks → Banner → (edit) → Where to show）**で選択します。

| 配置 | 表示イメージ |
|---|---|
| **注文履歴 — コンテンツブロック（Orders — content block）** | 注文履歴（注文一覧）ページに表示される、従来型のバナーカードです。 |
| **注文状況 — コンテンツブロック（Order status — content block）** | 注文状況ページに表示されるバナーカードです。 |
| **注文履歴 — 上部のお知らせ（Orders — top announcement）** | 注文履歴ページの最上部に表示される、閉じられる細いストリップです。 |
| **注文状況 — 上部のお知らせ（Order status — top announcement）** | 注文状況ページに表示される同じストリップです。 |
| **プロフィール — 上部のお知らせ（Profile — top announcement）** | プロフィールページの上部に表示されるストリップです。 |

お知らせストリップに関する注意点：ストリップはShopifyのお知らせ用スロットで表示されるため、**トーン**と**閉じる**の設定は反映されません（ストリップは仕様上、常に閉じることができます）。また、ボタンはインラインのリンクとして表示されます。ページごとに、対応する**Optimalify Banner**ブロックを顧客アカウントのエディターに追加することをお忘れなく。詳しくは[ページにブロックを追加する](add-blocks-in-editor.md)をご覧ください。

## 表示する対象（ターゲティング）

バナーの編集画面で、**対象（Audience）**を**ターゲット指定（Targeted）**に設定し、条件を追加します。

| 条件 | 一致する場合… | 必要なもの |
|---|---|---|
| **顧客タグ（Customer tag）** | お客様が、指定したタグのいずれかを持っている。 | 追加の権限* |
| **新規 / リピーター（New vs returning）** | お客様の注文が1件以下（新規）／2件以上（リピーター）である。 | 追加の権限* |
| **国（Country）** | お客様が、指定した国コード（例：`VN, US`）のいずれかからアクセスしている。 | — |
| **言語（Language）** | アカウントが、指定した言語（例：`vi, en`）のいずれかで表示されている。 | — |
| **B2B顧客（B2B customer）** | ログイン中のお客様がB2Bの会社に所属している。 | — |
| **プロフィール項目（Profile field）** | 保存されたプロフィールの回答（例：サイズ）が、指定した値のいずれかと一致する。 | プロフィールブロック |
| **誕生月（Birthday month）** | お客様が保存した誕生日が、現在の月に当たる。 | プロフィールブロック |
| **スケジュール（Schedule）** | 現在が、指定した開始日時〜終了日時（UTC）の間である。 | — |

条件は、**すべて（all）**（すべての条件に一致）または**いずれか（any）**（1つ以上に一致）で組み合わせられます。各条件は**否定**（「一致しないこと」）にもできます。

*タグと注文履歴の条件を使うには、アプリにShopifyの追加権限`read_customers` / `read_orders`を付与する必要があります。付与されるまでは、これらの条件をお客様ごとに判定できません。その場合の動作は、下記の**「判定できない場合（If we can't tell）」**の設定で決まります。

## 「判定できない場合」

一部の条件は、常に判定できるとは限りません。たとえば、まだサインインしていない訪問者や、付与していない権限が必要な条件などです。その場合の動作を選択します。

- **バナーを非表示にする（推奨）** — プロモーションやターゲット指定のオファーに最も安全な設定です。
- **バナーを表示する** — 見逃すよりは多めに表示したい、一般的なお知らせに適しています。

## 活用例

- **誕生日オファー：** 対象 = ターゲット指定・条件は**誕生月**・温かみのある見出しと割引コードのボタンを設定します。お客様が誕生日を保存できるよう、プロフィールブロックと組み合わせてください。
- **VIP限定のお知らせ：** 条件は**顧客タグ** = `VIP`（追加の権限が必要です）。
- **キャンペーン期間：** 開始日時と終了日時を指定した**スケジュール**条件を使うと、バナーが自動でオン・オフになります。

## 表示されない場合

全員向けのバナーは、これまでと同じ動作です。ターゲット指定のバナーの場合、エディターのプレビューでは（スタイルを調整できるよう）常にバナーが表示される点にご注意ください。ターゲティングが適用されるのは、公開ページを見る実際のお客様のみです。チェックリストの全体は[よくある質問とトラブルシューティング](faq-troubleshooting.md)に掲載しています。
