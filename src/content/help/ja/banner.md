お客様の**注文履歴**ページと**注文状況**ページに、セール、配送のお知らせ、ポリシー変更、ウェルカムメッセージなどを表示できます。バナーの文言は、入力したとおりに表示されます。

## 表示される場所
注文履歴（注文一覧）ページと注文状況ページに表示されます。どのページに配置するかはエディターで選択します。詳しくは[ページにブロックを追加する](add-blocks-in-editor.md)をご覧ください。

## バナーを作成する
1. **アプリ → Optimalify → ブロック → バナー（Apps → Optimalify → Blocks → Banner）**を開きます。
2. **バナーを追加（Add banner）**をクリックします（複数作成できます）。
3. 下記の項目を入力し、**ステータス（Status）を有効（Active）**に設定して、**作成 / 保存（Create / Save）**をクリックします。
4. 顧客アカウントのエディターで「Optimalify Banner」ブロック（**Optimalify Banner**）を追加します。バナーが複数ある場合は、**エントリーハンドル（Entry handle）**も設定してください。

## 項目

| 項目 | 説明 |
|---|---|
| **内部名（Internal name）** | ストア運営者だけに表示される名前です。後でバナーを見つけやすくするためのラベルです（最大60文字）。 |
| **ステータス（Status）** | **有効**にするとお客様に表示され、**下書き**にすると非表示のままになります。 |
| **見出し（Heading）** | 太字のタイトルです（最大80文字）。 |
| **メッセージ（Message）** | 本文です（最大300文字）。 |
| **トーン（Tone）** | 色や強調の度合いです：`auto`、`info`、`success`、`warning`、`critical`。 |
| **お客様がバナーを閉じられるようにする（Let customers dismiss the banner）** | オンにすると、お客様がバナーを閉じることができます。 |
| **ボタン（任意）（Button (optional)）** | コールトゥアクションを追加できます：**ボタンのラベル（Button label）**（最大40文字）と**ボタンのリンクURL（Button link URL）**。 |

## ヒント
- **トーン**は見た目のスタイルを決めます。`warning`や`critical`は本当に重要なお知らせにだけ控えめに使い、`success`は良いニュース、`info`（または`auto`）は日常的なメッセージに使いましょう。
- 見出しは短くまとめ、詳しい内容はメッセージに記載します。
- 右側の**ライブプレビュー**は、入力に合わせてリアルタイムで更新されます。
- バナーのテキストは、アプリ内の**翻訳（Translations）**、またはTranslate & Adaptで翻訳できます。詳しくは[ブロックを翻訳する](translations.md)をご覧ください。

## ページごとに異なるバナーを表示する
複数のバナーを作成し、各ページにブロックを配置して、そのページに表示したいバナーの**エントリーハンドル**を設定します。ハンドルを空欄にすると、デフォルト（最初の有効なバナー）が表示されます。詳しくは[「表示するエントリーを選ぶ — エントリーハンドル」セクション](add-blocks-in-editor.md)をご覧ください。

## 表示されない場合
バナーが**有効**になっていること、ブロックがエディターで**追加・保存されている**こと、**ログインした状態**で確認していることをご確認ください。チェックリストの全体は[よくある質問とトラブルシューティング](faq-troubleshooting.md)に掲載しています。
