## ブロックがページに表示されません
次の項目を順番に確認してください。

1. **エントリーは有効になっていますか？** Optimalify でブロックを開き、**ステータス（Status）＝有効（Active）**（下書き（Draft）ではありません）に設定して、**保存（Save）**します。
2. **エディターで追加しましたか？** ブロックは、**チェックアウトと顧客アカウントのエディターで追加**し、そこでも**保存（Save）**して初めて表示されます。詳しくは[ページにブロックを追加する](add-blocks-in-editor.md)をご覧ください。
3. **ログインしていますか？** 顧客アカウントのページは、**ログイン済み**のお客様にのみ表示されます。ストアの顧客アカウントにログインした状態でプレビューしてください。
4. **エントリーハンドルは一致していますか？** 配置に**エントリーハンドル（Entry handle）**を設定している場合は、**有効な**エントリーのハンドルと一致している必要があります。**空欄**にすると、デフォルトのエントリー（最初の有効なエントリー）が表示されます。
5. **正しいページですか？** 各ブロックは対応するページが決まっています（例：トラストバッジは注文状況ページのみ）。[ページにブロックを追加する](add-blocks-in-editor.md)の表をご確認ください。

## Optimalify で保存したのにページが変わりません
Optimalify でのブロックの設定と、**エディターへの配置**は別々の手順です。両方とも完了している場合は、アカウントページを再読み込みしてください（変更はほぼ即時に反映されますが、キャッシュされた表示が残っている場合は強制再読み込みでクリアされます）。

## ページごとに異なる内容を表示できますか？
はい、可能です。複数のエントリーを作成し（バナーは複数作成できますが、その他のブロックは1つです）、各配置の**エントリーハンドル（Entry handle）**に、そのページで表示したいエントリーを指定します。空欄の場合はデフォルトのエントリーが表示されます。

## 各ブロックはどのページに配置できますか？
| ブロック | ページ |
|---|---|
| バナー | 注文履歴、注文状況 |
| サポート連絡先 | フッター（すべてのアカウントページ） |
| トラストバッジ | 注文状況（配送状況の詳細の後） |
| お支払いアイコン | 注文状況、注文履歴、プロフィール、フッター |
| プロフィール情報の取得 | プロフィール、注文履歴、注文状況 |
| ソーシャルリンク | 注文状況、注文履歴、プロフィール、フッター |
| よくある質問(FAQ) | 注文状況、注文履歴、プロフィール |
| ストアポリシー | 注文状況、注文履歴、プロフィール |
| リッチコンテンツ | 注文状況、注文履歴、プロフィール、フッター |

## ブロックのテキストを翻訳できますか？
はい、可能です。Optimalify の**翻訳（Translations）**または Translate & Adapt で翻訳してください。お客様にはご自身の言語で表示され、翻訳がない場合は元のテキストが表示されます。詳しくは[ブロックを翻訳する](translations.md)をご覧ください。

## バッジのロゴはどこから取得しますか？
お使いのパソコンからアップロードするか、ストアの**ファイル（Files）**（設定 → ファイル（Settings → Files））にある既存の画像を選択できます。アップロードした画像もファイルに保存されます。ロゴを設定すると、バッジのアイコンが置き換わります。

## Optimalify は顧客データを収集しますか？
- **バナー、サポート連絡先、トラストバッジ、お支払いアイコン：** 顧客データは扱いません。設定した内容を表示するだけです。
- **プロフィール情報の取得：** お客様が任意で入力した情報（誕生日、サイズ、連絡方法の希望など）を、顧客レコードのメタフィールドとして保存します。管理画面でご確認いただけます。プライバシーポリシーに沿ってご利用ください。

## お客様はバナーを閉じることができますか？
そのバナーで**「お客様がバナーを閉じられるようにする」（Let customers dismiss the banner）**をオンにした場合のみ可能です。

## 解決しない場合は
ストアのURL、該当のブロック、スクリーンショットを添えて **mia@optimalify.org** までメールでご連絡ください。サポートいたします。
