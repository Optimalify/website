Optimalifyを設定し、最大限に活用するために必要な情報をまとめています。Optimalifyは、Shopifyの**顧客アカウント**ページに、バナー、トラストバッジ、お支払いアイコン、サポート情報、プロフィール取得、請求書のダウンロードを追加するアプリです。

初めての方は、まず**[はじめに](getting-started.md)**をお読みいただき、続けて**[顧客アカウントページにブロックを追加する](add-blocks-in-editor.md)**をご覧ください。

## ブロック一覧

| ブロック | 表示される場所 | 設定場所 |
|---|---|---|
| **バナー** | 注文履歴 + 注文状況（カードまたは上部のお知らせストリップ）+ プロフィールのストリップ | アプリ → Optimalify → ブロック → バナー（Apps → Optimalify → Blocks → Banner） |
| **請求書のダウンロード** | 注文履歴 + 注文状況の注文アクションメニュー | ブロック → 請求書（Blocks → Invoice） |
| **サポート** | すべてのアカウントページのフッター | ブロック → サポート（Blocks → Support） |
| **トラストバッジ** | 注文状況ページ（配送情報の後） | ブロック → バッジ（Blocks → Badges） |
| **お支払いアイコン** | 注文状況、注文履歴、プロフィール、フッター | ブロック → お支払い（Blocks → Payments） |
| **プロフィール取得** | プロフィールページ（+ 注文履歴 / 注文状況） | ブロック → プロフィール（Blocks → Profile） |
| **ソーシャルリンク** | 注文状況、注文履歴、プロフィール、フッター | ブロック → ソーシャルリンク（Blocks → Social links） |
| **よくある質問(FAQ)** | 注文状況、注文履歴、プロフィール | ブロック → FAQ（Blocks → FAQ） |
| **ストアポリシー** | 注文状況、注文履歴、プロフィール | ブロック → ストアポリシー（Blocks → Store policies） |
| **リッチコンテンツ** | 注文状況、注文履歴、プロフィール、フッター | ブロック → リッチコンテンツ（Blocks → Rich content） |

お困りの際は、**mia@optimalify.org**までメールでお問い合わせください。
