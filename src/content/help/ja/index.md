Optimalifyを設定し、最大限に活用するために必要な情報をまとめています。Optimalifyは、Shopifyの**顧客アカウント**ページに、お知らせバナー、信頼バッジ、決済アイコン、お問い合わせ先、プロフィール項目、請求書ダウンロードを追加するアプリです。

初めての方は、まず**[はじめに](getting-started.md)**をお読みいただき、続けて**[顧客アカウントページにブロックを追加する](add-blocks-in-editor.md)**をご覧ください。

## ブロック一覧

| ブロック | 表示される場所 | 設定場所 |
|---|---|---|
| **お知らせバナー** | 注文履歴 + 注文状況（カードまたは上部のお知らせストリップ）+ プロフィールのストリップ | アプリ → Optimalify → ブロック → お知らせバナー（Apps → Optimalify → Blocks → Announcement banner） |
| **請求書ダウンロード** | 注文履歴 + 注文状況の注文アクションメニュー | ブロック → 請求書ダウンロード（Blocks → Invoice download） |
| **お問い合わせ先** | すべてのアカウントページのフッター | ブロック → お問い合わせ先（Blocks → Support contact） |
| **信頼バッジ** | 注文状況ページ（配送情報の後） | ブロック → 信頼バッジ（Blocks → Trust badges） |
| **決済アイコン** | 注文状況、注文履歴、プロフィール、フッター | ブロック → 決済アイコン（Blocks → Payment icons） |
| **プロフィール項目** | プロフィールページ（+ 注文履歴 / 注文状況） | ブロック → プロフィール項目（Blocks → Profile fields） |
| **SNSリンク** | 注文状況、注文履歴、プロフィール、フッター | ブロック → SNSリンク（Blocks → Social links） |
| **よくある質問** | 注文状況、注文履歴、プロフィール | ブロック → よくある質問（Blocks → FAQ） |
| **ストアポリシー** | 注文状況、注文履歴、プロフィール | ブロック → ストアポリシー（Blocks → Store policies） |
| **コンテンツセクション** | 注文状況、注文履歴、プロフィール、フッター | ブロック → コンテンツセクション（Blocks → Content section） |
| **もう一度購入** | 注文履歴（グリッド）、注文状況（各商品） | ブロック → もう一度購入（Blocks → Buy again） |
| **会員ウォレット** | プロフィール、注文履歴 | ブロック → 会員ウォレット（Blocks → Member wallet） |
| **カスタムページ** | アカウント内の独自のページ（アカウントメニューから開きます） | ブロック → カスタムページ（Blocks → Custom pages） |

お困りの際は、**mia@optimalify.org**までメールでお問い合わせください。
