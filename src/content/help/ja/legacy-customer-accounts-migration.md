Shopifyは**2026年2月26日に旧顧客アカウントを非推奨**にしました。今後は機能の追加や技術サポートが行われず、Shopifyはすべての加盟店に最新の顧客アカウントへの移行を求めています。新しい顧客アカウントに切り替えると、旧アカウントのページ（`/account`）にテーマで加えていたカスタマイズは**引き継がれません**。旧アカウントのLiquidページを前提にしていたアプリも、新しい顧客アカウントでは動作しません。

このページでは、移行時によく失われるものと、Optimalifyのブロックで再現する方法をまとめます。設定はアプリと顧客アカウントのエディターで行い、テーマのコードは不要です。

> **日付について：**Shopifyは、旧顧客アカウントの最終的な終了日は2026年内に発表するとしています。最後に確認した2026年11月10日時点では、日付は公表されていなかったため、このページでは日付を示していません。詳しくは[Shopifyの変更履歴](https://shopify.dev/changelog/posts/legacy-customer-accounts-are-deprecated)と、[移行チェックリスト](/blog/legacy-customer-accounts-deprecated-checklist)をご覧ください。

## 何を、どう戻すか

| 旧アカウントのページにあったもの | 再現する方法 |
|---|---|
| 注文の請求書・領収書を取得する手段 | [請求書ダウンロード](invoice.md)：各注文に**請求書をダウンロード**のPDFアクションを追加。お客様の言語で表示 |
| プロフィールの誕生日、連絡方法、VAT番号 | [プロフィール項目](profile.md)：誕生日、希望サイズ、連絡方法、VAT番号などの独自項目 |
| 再注文のショートカット | [もう一度購入](buy-again.md)：よく購入する商品のグリッドと、各注文行の**もう一度購入**ボタン |
| ポイントや会員ランクの表示 | [会員ウォレット](member-wallet.md)：ロイヤルティアプリが保存した顧客メタフィールドから、ポイントとランクを表示 |
| お知らせ、よくある質問、返品ポリシー、販促カード | [お知らせバナー](banner.md)、[よくある質問](faq.md)、[ストアポリシー](store-policies.md)、[コンテンツセクション](rich-content.md) |
| お問い合わせ先 | [お問い合わせ先](support.md) |

### 請求書

テーマのコードやLiquidベースのアプリで請求書を提供していた場合、その機能は新しい顧客アカウントには引き継がれません。請求書ブロックを使うと、注文に**請求書をダウンロード**のアクションを追加できます。PDFは英語、ドイツ語、フランス語、スペイン語、オランダ語、イタリア語、ベトナム語、日本語に対応しています。日本のストア向けには、適格請求書の記載項目（登録番号など）も任意で設定できます。手順は[適格請求書をマイページからダウンロードできるようにする](qualified-invoice-my-page.md)をご覧ください。

### 誕生日とVAT番号

プロフィール項目では、**プロフィール**ページで誕生日や独自の項目を集められます。回答はShopify上のお客様の情報に保存されます。VAT番号の項目では、**EU形式のチェック**（国コードと番号の形式）を使えます。これは形式のチェックのみで、番号が実在するかどうかの照合は行いません。

### もう一度購入

お客様がよく購入する商品がグリッドで表示され、ワンクリックで再注文できます。消耗品や詰め替え商品に向いています。

### ポイント表示

Optimalifyがポイントを計算することはありません。会員ウォレットは、**ロイヤルティアプリがお客様に保存しているポイントとランク**を表示します。**LoyaltyLion**と**Rivo**のプリセットがあり、アプリがメタフィールドに書き込んだ値を読み取ります。**Smile.io**から取得できるのはVIPランクのみで、ポイントは取得できません。お客様のメタフィールドを任意に指定することもできます。

### 独自コンテンツとよくある質問

お知らせ、よくある質問、ポリシー、販促カードをブロックとして作り直し、エディターの好きな位置に配置できます。多くのブロックでは、表示するお客様を絞り込めます。詳しくは[バナーの配置とターゲティング](banner-targeting.md)をご覧ください。

## Optimalifyで置き換えられないもの

Shopifyの移行ガイドには、引き継がれないものとして、旧アカウントをトリガーにしたワークフロー、旧アカウントのステータスで絞り込んだセグメント、テーマに組み込んだ独自のログイン・会員登録の仕組みなどが挙げられています。これらはOptimalifyで再現するものではありません。アップグレードの前に[チェックリスト](/blog/legacy-customer-accounts-deprecated-checklist)をご確認ください。

## 進め方

1. Shopify管理画面の**設定 → 顧客アカウント**で、旧ページが担っていた機能を書き出します。
2. Optimalifyをインストールし、上記のブロックを設定します。[はじめに](getting-started.md)と[ページにブロックを追加する](add-blocks-in-editor.md)をご覧ください。
3. ログイン済みのテストアカウントで、新しい顧客アカウントの表示を確認します。
4. **設定 → 顧客アカウント**からアップグレードします。

無料プランでは、同時に有効にできるブロックは1つです。まずはお客様にとって最も必要なものから始めてください。プランの内容はApp Storeの掲載ページでご確認いただけます。
