会員に現在の状況をお見せします。**会員ウォレット**は、お客様の**ポイント残高**、**会員ランク**、そして実店舗でスタッフが読み取れる**QRコード**（任意）を表示するカードです。

## 表示される場所
**プロフィール（Profile）**ページと**注文履歴（Orders）**ページ。エディターで、表示したい場所に**Optimalify Member wallet**（会員ウォレット）ブロックを追加します。

## 値の取得元
Optimalifyはポイントを計算しません。ご自身や会員管理アプリ、Shopify Flowなどが書き込んだ**顧客メタフィールド**から読み取ります。表示したい値ごとに、次の設定を行ってください。

1. Shopify管理画面の**設定 → カスタムデータ → 顧客**で、メタフィールドの定義を作成（または開く）します。例：`custom.loyalty_points`（数値またはテキスト）、`custom.member_rank`（テキスト）。
2. **カスタマーアカウントからのアクセス**を**読み取り**にします。設定しないと、お客様に値が表示されません。

他のアプリが管理するメタフィールド（`$app`ネームスペース）は読み取れません。ストアクレジットは表示されません。

## 設定手順
1. **アプリ → Optimalify → ブロック → 会員ウォレット（Apps → Optimalify → Blocks → Member wallet）**を開きます。
2. 下記の項目を入力し、**ステータス（Status）を「有効（Active）」**にして**保存（Save）**します。メタフィールドが見つからない、またはお客様から読み取れない場合は、ページに警告が表示されます。
3. 顧客アカウントのエディターで**Optimalify Member wallet**（会員ウォレット）ブロックを追加します。詳しくは[ページにブロックを追加する](add-blocks-in-editor.md)をご覧ください。

## 項目

| 項目 | 補足 |
|---|---|
| **カードのタイトル** | 空欄の場合は、お客様の言語に合わせた標準のタイトルを表示します。 |
| **ポイントのメタフィールド** | 顧客メタフィールドを「ネームスペース.キー」の形式で入力します（例：`custom.loyalty_points`）。空欄にするとポイントは表示されません。 |
| **ランクのメタフィールド** | 顧客メタフィールドを「ネームスペース.キー」の形式で入力します（例：`custom.member_rank`）。空欄にするとランクは表示されません。 |
| **ポイントの表示名 / ランクの表示名** | 任意です。空欄の場合は標準の表示名が使われます。 |
| **会員用QRコードを表示する** | QRコードの内容は**顧客ID**、または会員番号などの**顧客メタフィールド**から選べます。 |
| **値の前に付ける文字** | 任意です（例：`MEMBER-`）。POSが接頭辞を必要とする場合に便利です。 |
| **QRコードの下の一文** | 任意の説明文です。 |

## ヒント
- 値が設定されていない項目は、そのお客様には表示されません。すべての値がないお客様には、カード自体が表示されません。
- エディターでは、ログインしているお客様がいないため、実際の数値ではなく短い案内が表示されます。仕上がりは、ストアでテスト用のお客様アカウントにログインして確認してください。

## プラン
- **無料**プランでは同時に**有効にできるブロックは1つ**です。**Pro**ではすべてのブロックを利用できます。

表示されない場合は、[FAQとトラブルシューティング](faq-troubleshooting.md)をご覧ください。
