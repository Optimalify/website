アカウントページに、プロモーションカード、ブランドストーリー、キャンペーンを追加できます。画像、見出し、短いテキスト、そしてお好みでボタンを設定できます。

## 表示される場所
**注文状況**ページ、**注文履歴**ページ、**プロフィール**ページ、**フッター**。エディターで表示したい場所に「Optimalify Rich Content」ブロック（**Optimalify Rich Content**）を追加します。

## 設定手順
1. **アプリ → Optimalify → ブロック → リッチコンテンツ（Apps → Optimalify → Blocks → Rich content）**を開きます。
2. 下記の項目を入力し、**ステータス（Status）を「有効（Active）」**にして**保存（Save）**します。
3. チェックアウトと顧客アカウントのエディターで **Optimalify Rich Content** ブロックを追加します。詳しくは[ページにブロックを追加する](add-blocks-in-editor.md)をご覧ください。

## 項目

| 項目 | 補足 |
|---|---|
| **画像（Image）** | お使いのパソコンからアップロードできます。アップロードした画像はストアの **Shopify Files** に保存されます。既存のファイルを選ぶことも可能です。 |
| **見出し（Heading）** | 最大80文字です。 |
| **テキスト（Text）** | 最大500文字です。 |
| **ボタン（Button）** | 任意です。**ラベル**（最大30文字）と、`https://` で始まる**完全なリンク**を設定します。 |
| **レイアウト（Layout）** | **画像を左（Image left）**、**画像を右（Image right）**、**画像を上（Image on top）**、**テキストのみ（Text only）**から選べます。 |

画面幅が狭い場合、**画像を左**と**画像を右**は**画像を上**の表示に切り替わります。

## ヒント
- 新商品の発売などでは[バナー](banner.md)と組み合わせると効果的です。バナーで告知し、カードでストーリーを伝えます。
- ボタン付きのシンプルなお知らせには**テキストのみ**を使いましょう。
- ボタンのラベルは「セール会場へ」のように、行動を促す表現にしましょう。

## 表示対象とプラン
- **表示条件**を使うと、特定のお客様（タグ、国など）にだけブロックを表示できます。詳しくは[バナーの配置とターゲティング](banner-targeting.md)をご覧ください。
- **無料**プランでは同時に**有効にできるブロックは1つ**です。**Pro**ではすべてのブロックを利用できます。

表示されない場合は、[FAQとトラブルシューティング](faq-troubleshooting.md)をご覧ください。
