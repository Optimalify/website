お客様がヘルプを探す場所、つまり**すべての顧客アカウントページのフッター**に連絡手段を配置できます。メール、電話、WhatsApp、ヘルプセンターへのリンク、「問題を報告する」リンクを、1つのすっきりしたブロックにまとめて表示します。

## 表示される場所
すべてのアカウントページ（注文履歴、注文状況、プロフィール）のフッターです。エディターで **Optimalify Support**（サポート連絡先）ブロックを1回追加すると、アカウントエリア全体に表示されます。

## 設定方法
1. **アプリ → Optimalify → ブロック → サポート（Apps → Optimalify → Blocks → Support）**を開きます。
2. 項目（下記）を入力し、**ステータス（Status）＝有効（Active）**に設定します。
3. **保存（Save）**してから、チェックアウトと顧客アカウントのエディターで **Optimalify Support** ブロックを追加します。

## 項目

| 項目 | 備考 |
|---|---|
| **見出し（Heading）** | セクションのタイトルです。例：「お困りですか？」（最大80文字）。 |
| **サブテキスト（Subtext）** | 見出しの下に表示する短い1行です（最大300文字）。 |
| **サポート用メールアドレス（Support email）** | `mailto:` リンクとして表示されます。 |
| **電話番号（Phone）** | タップで発信できるリンクとして表示されます。 |
| **WhatsApp** | WhatsAppの番号です。チャットが開きます（`wa.me`）。 |
| **ヘルプセンターURL（Help center URL）** | ヘルプやよくある質問(FAQ)ページへのリンクです。 |
| **問題の報告URL（Report a problem URL）** | 問題を報告するためのフォームやページへのリンクです。 |
| **レイアウト（Layout）** | 連絡手段の並べ方です：**リスト（List）**、**横並び（Inline）**、**グリッド（Grid）**、**ボタン（Buttons）**。 |
| **配置（Alignment）** | **左揃え（Left）**または**中央揃え（Center）**です（横並び／グリッドのレイアウトに適用されます）。 |

使用しない連絡手段は空欄にすると非表示になります。入力した項目のみが表示されます。

## ヒント
- 連絡手段を目立たせたい場合は**ボタン**レイアウト、コンパクトに見せたい場合は**リスト**を使用してください。
- **ヘルプセンターURL**には、*このヘルプセンター*やご自身のよくある質問(FAQ)ページへのリンクを設定するのがおすすめです。
- 同時に使用されるサポート連絡先のエントリーは1つだけです。表示するには、ブロックの**エントリーハンドル（Entry handle）**を空欄のままにしてください。

## プライバシー
サポート連絡先ブロックは、入力した連絡先情報のみを表示します。顧客データは読み取りません。

表示されない場合は、[よくある質問(FAQ)とトラブルシューティング](faq-troubleshooting.md)をご覧ください。
