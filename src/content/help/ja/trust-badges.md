安全なチェックアウト、返金保証、スピーディな配送などのトラストバッジを**注文状況（Order status）**ページの配送状況の詳細の直後に表示して、お客様に安心感を与えます。

## 表示される場所
注文状況ページの、配送状況の詳細セクションの後です。エディターで **Optimalify Badges**（トラストバッジ）ブロックを追加します。

## 設定方法
1. **アプリ → Optimalify → ブロック → バッジ（Apps → Optimalify → Blocks → Badges）**を開きます。
2. 見出し／メッセージを入力し、バッジ（下記）を追加して、**ステータス（Status）＝有効（Active）**に設定し、**保存（Save）**します。
3. チェックアウトと顧客アカウントのエディターで **Optimalify Badges** ブロックを追加します。

## コンテンツ
- バッジの上に表示される**見出し（Heading）**（最大80文字）と**メッセージ（Message）**（最大300文字）。

## バッジ（最大8個）
**プリセット**のバッジはワンクリックで追加でき、**カスタム**バッジも作成できます。すべてのバッジが同じ編集行を使うため、プリセットも自由に編集できます。

**プリセット：** 安全なチェックアウト · 返金保証 · スピーディな配送 · 正規品保証。

**各バッジの項目：**

| 項目 | 備考 |
|---|---|
| **タイトル（Title）** | バッジのラベルです（最大40文字）。 |
| **説明（Description）** | タイトルの下に表示する短い1行です。カードスタイルで表示されます（最大80文字）。 |
| **アイコン（Icon）** | 用意されたセット（ロック、チェック付き丸、チェック、クレジットカード、返金、割引、配送、返品、星、ギフトカード、世界、ストア、高速）から選択します。**なし（None）**も選べます。 |
| **トーン（Tone）** | アイコンの色です：`auto`、`neutral`、`info`、`success`、`warning`、`critical`。 |
| **ロゴ（Logo）** | 任意です。画像（JPG、PNG、WebP、GIF、SVG、最大5 MB）をアップロードするか、ストアの**ファイル（Files）**（設定 → ファイル（Settings → Files））から選択します。ロゴを設定すると、アイコンが**置き換わります**。 |

並べ替えには**上へ移動／下へ移動（Move up / Move down）**、バッジの**表示／非表示**にはトグル、削除には**削除（Remove）**を使用します。

> **ロゴは常にストアのファイルに保存されます。** ここでアップロードした画像は設定 → ファイルに保存されるため、お客様にはShopifyがホストする画像のみが表示されます。

## 表示設定

| オプション | 選択肢 |
|---|---|
| **バッジスタイル（Badge style）** | **カード（Cards）**（アイコン＋タイトル＋説明）または**コンパクトなピル（Compact pills）**（チップ形式）。 |
| **レイアウト（Layout）** | **横一列（Inline row）**、**2列（Two columns）**、**縦並び（Stacked）**。 |
| **配置（Alignment）** | **左揃え（Left）**または**中央揃え（Center）**。 |

## ヒント
- 説明文を使う場合は**カード**スタイル、すっきりした1行のストリップにしたい場合は**コンパクトなピル**が最適です。
- プリセットにブランドの**ロゴ**を追加できます（例：「スピーディな配送」に配送業者のロゴを設定）。
- 厳選した3～4個のバッジにとどめましょう。多ければ良いとは限りません。

表示されない場合は、[よくある質問(FAQ)とトラブルシューティング](faq-troubleshooting.md)をご覧ください。
